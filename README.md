# 📚 EduPlatform — Образовательная платформа для России и СНГ

**Статус:** В разработке  
**Архитектура:** Микросервисы (Python FastAPI + Next.js)  
**Инфраструктура:** Docker, PostgreSQL, Redis

---

## 🎯 Миссия
Собрать в себе все полезные качества для пользы людей.

## 🛠 Технологический стек

| Компонент | Технология | Причина |
| :--- | :--- | :--- |
| **Бэкенд** | Python 3.11 / FastAPI | Скорость разработки, производительность |
| **Фронтенд** | Next.js 14 (React + TypeScript) | SEO, скорость, современный подход |
| **База данных** | PostgreSQL 16 | Надёжность, сложные запросы |
| **Кеш** | Redis | Скорость, сессии, очереди |
| **Хранилище** | S3 (Yandex Cloud / VK Cloud) | Надёжность, масштабируемость |
| **Платежи** | ЮKassa + СБП | Работают в России, низкая комиссия |
| **Контейнеризация** | Docker + Docker Compose | Универсальность, изоляция |
| **Хостинг** | Yandex Cloud / VK Cloud | Гранты, соответствие 152-ФЗ |

## 📋 Как запустить проект

### 1. Запустить бэкенд (Docker)
```bash
docker-compose up -d


2. Запустить фронтенд
bash

npm install
npm run dev


3. Открыть в браузере
