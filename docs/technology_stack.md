# 🛠 Технологический стек — обоснование выбора

> Документ фиксирует причины выбора каждой технологии для образовательной платформы.  
> Обновляется по мере принятия новых решений.

---

## ☁️ Хостинг и облачная инфраструктура

**Выбор:** Yandex Cloud / VK Cloud

**Причины:**
1. **Соответствие 152-ФЗ** — оба провайдера сертифицированы для работы с персональными данными граждан РФ. Это обязательное требование для образовательной платформы со школьниками.
2. **Грантовая поддержка** — VK Cloud даёт до 2 000 000 ₽, Yandex Cloud — до 1 000 000 ₽ + отдельный AI-грант. Это позволяет запустить проект без вложений.
3. **Отраслевой опыт** — провайдеры уже используются в крупных EdTech-проектах (например, Karpov.Courses).
4. **Стабильность** — работа внутри РФ гарантирует отсутствие блокировок и стабильный доступ для пользователей из России и СНГ.

**Решение:** На старте подаём заявки на гранты в оба облака, сравниваем условия и выбираем основного провайдера. Второй оставляем как резервный или для распределения нагрузки.

## 💾 Хранилище файлов (видео, картинки, документы)

**Выбор:** S3-совместимое объектное хранилище (Object Storage) от Yandex Cloud / VK Cloud

**Причины:**
1. **Надёжность** — S3-хранилища проектируются с надёжностью 99,999999999% (11 девяток).
2. **Масштабируемость** — объём хранилища растёт автоматически, не нужно докупать диски.
3. **Экономия** — стоимость хранения в S3 ниже, чем на обычных серверных дисках, особенно для видео.
4. **Производительность** — видео транслируется напрямую из S3 через CDN, не нагружая сервер с основным приложением.
5. **Безопасность** — доступ к файлам можно ограничивать через временные подписанные ссылки.

**Решение:** Используем S3 из того же облака, что и основной хостинг. Это упрощает интеграцию и снижает затраты на трафик.

## ⚙️ Бэкенд (серверная логика)

**Выбор:** Python 3.11+ / FastAPI

**Причины:**
1. **Скорость разработки** — на Python писать в 2–3 раза быстрее, чем на Java или C#.
2. **Производительность** — FastAPI один из самых быстрых фреймворков для Python, сравним с Node.js и Go.
3. **Автоматическая документация** — FastAPI генерирует Swagger/OpenAPI документацию автоматически, что ускоряет разработку и тестирование.
4. **Большое сообщество** — множество готовых библиотек для всего: аутентификация, платежи, AI, работа с видео.
5. **Асинхронность** — FastAPI поддерживает асинхронные запросы, что важно для работы с видео и чатами в реальном времени.

**Решение:** Используем Python + FastAPI для всех микросервисов. Единый стек упрощает разработку и поддержку.

## 🖥️ Фронтенд (интерфейс)

**Выбор:** Next.js 14 (React + TypeScript)

**Причины:**
1. **SEO** — Next.js умеет рендерить страницы на сервере (SSR), что критически важно для поисковой выдачи в Google и Яндексе.
2. **Скорость** — серверный рендеринг даёт мгновенную загрузку первой страницы, даже на медленном интернете.
3. **TypeScript** — строгая типизация ловит ошибки на этапе написания кода, а не в продакшене.
4. **Масштабируемость** — React позволяет легко разбивать интерфейс на переиспользуемые компоненты.
5. **Готовые решения** — огромное количество библиотек для UI (дашборды, плееры, формы).

**Решение:** Используем Next.js 14 как основу для всего фронтенда. В будущем это позволит легко сделать мобильное приложение на React Native, переиспользуя логику.

## 🗄️ Базы данных

### Основная БД
**Выбор:** PostgreSQL 16

**Причины:**
1. **Надёжность** — PostgreSQL считается самой надёжной реляционной БД, используется в банках и госструктурах.
2. **Сложные запросы** — легко делать выборки с JOIN, фильтрацией, агрегацией (нужно для отчётов и аналитики).
3. **Полнотекстовый поиск** — встроенный поиск по тексту лекций и курсов.
4. **Бесплатно** — полностью Open Source, нет лицензионных отчислений.
5. **Масштабируемость** — поддерживает репликацию и шардирование, если нагрузка вырастет.

### Кеш и сессии
**Выбор:** Redis

**Причины:**
1. **Скорость** — все данные хранятся в оперативной памяти, запросы за микросекунды.
2. **Сессии пользователей** — быстрое хранение JWT-токенов и состояния.
3. **Кеширование страниц** — можно кешировать часто запрашиваемые страницы (главная, список курсов), снижая нагрузку на БД.
4. **Очереди задач** — Redis можно использовать для фоновых задач (отправка писем, обработка видео).

## 📦 Контейнеризация и оркестрация

**Выбор:** Docker + Docker Compose (на старте), Kubernetes (в будущем)

**Причины:**
1. **Универсальность** — приложение работает одинаково на компьютере разработчика и на сервере.
2. **Изоляция** — каждый микросервис в своём контейнере, не мешают друг другу.
3. **Лёгкий запуск** — одна команда `docker-compose up` поднимает всю инфраструктуру (БД, Redis, бэкенд, фронтенд).
4. **Масштабирование** — когда пользователей станет много, легко перейти на Kubernetes в том же облаке.

## 🌐 Веб-сервер

**Выбор:** Nginx

**Причины:**
1. **Производительность** — Nginx обрабатывает тысячи соединений одновременно.
2. **Раздача статики** — отдаёт картинки, CSS, JS быстрее, чем серверное приложение.
3. **Проксирование** — перенаправляет запросы к нужным микросервисам.
4. **SSL-терминация** — работает с HTTPS-сертификатами.

---

## 📡 Платежи

**Выбор:** ЮKassa + СБП (Система быстрых платежей)

**Причины:**
1. **ЮKassa** — популярный российский агрегатор, легко подключается, поддерживает все способы оплаты (карты, СБП, электронные кошельки).
2. **СБП** — комиссия всего 0.4% против 2.5–2.8% у эквайринга. На больших оборотах экономия колоссальная.
3. **Рассрочка** — можно подключить сервисы типа "Долями" или "Сплит", чтобы повысить конверсию продаж.
4. **Соответствие законодательству** — все платежи проходят внутри РФ.

## 🤖 Искусственный интеллект (для адаптивного обучения)

**Выбор:** Yandex GPT (через API) или Open Source LLM (например, Llama 3)

**Причины:**
1. **Yandex GPT** — уже встроен в экосистему Яндекса, есть грант до 1 000 000 ₽ на AI-сервисы.
2. **Российская разработка** — не будет заблокирована, соответствует законодательству.
3. **Open Source** — если захотим развернуть свою нейросеть на своих серверах (для приватности данных учеников).

## 📌 Итоговое решение

Все технологии выбраны по трём принципам:
1. **Бесплатность** — Open Source или гранты.
2. **Надёжность** — проверенные в крупных проектах технологии.
3. **Законность** — соответствие 152-ФЗ и российскому законодательству.

Этот стек даёт нам возможность запустить платформу без вложений и масштабировать её до миллионов пользователей без переписывания кода.
